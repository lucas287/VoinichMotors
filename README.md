# Voinich Motors — Protótipo de interface

Repositório separado da implementação principal em PHP. Este projeto reúne uma versão de interface para apresentação de veículos, construída com tecnologias web.

## Tecnologias

- HTML
- CSS
- JavaScript

## Sobre o projeto

Protótipo visual com foco na apresentação de veículos e na experiência de navegação. A implementação principal com PHP e MySQL está em outro repositório:

[ Voinich Motors — sistema PHP/MySQL ](https://github.com/lucas287/siteATUALIZADO2.0)

## Executar

Abra o arquivo HTML principal no navegador. Caso o projeto utilize recursos locais, mantenha a estrutura de pastas e os arquivos de imagem juntos.

## Observação

Este repositório representa o protótipo de interface e não deve ser confundido com o sistema PHP/MySQL.
